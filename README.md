# Golden Coffee

Authors: Mukhitden Nurdaulet, Arlan Kudabay. Assignments 1 and 2: HTML and CSS.

To open the website, double-click index.html. No installation or server is needed.

The site has six pages: Home, Menu, Drinks, Feedback, Visit and colophon.html, which explains how we built it. Shared styles are in css/base.css. Each page also loads its own stylesheet from the css folder: index.css, menu.css, drinks.css, feedback.css, visit.css or colophon.css. There is no JavaScript.

The report is in report.pdf. The tags, attributes and line numbers are listed in checklist.md. The images folder contains cafe photos and page screenshots used in the report.
