How I built this site

Four local pages

I chose Golden Coffee for my project and built the site with HTML. This page is called a colophon: it explains how I made the site. The project includes a home page, a menu, a visit page and this explanation.

The HTML files are in the same folder. I used their filenames in the links, so the pages open directly from my computer without a server. I did not add CSS or JavaScript. The browser uses its default appearance for headings and form fields.

Why I used these elements

Each breakfast is inside an article because its description makes sense on its own. I used main for the page content and nav for the links. These tags make the page structure easier to understand. The address and phone number appear in every footer. 

<nav aria-label="Pages">
  <ul>
    <li>
      <a href="menu.html">
        Menu
      </a>
    </li>
  </ul>
</nav>

Opening the files and using the form

I open a file with Ctrl + O on Windows or Cmd + O on a Mac. The home tab shows Golden Coffee - Coffee shop in Astana. I marked the required form fields and used the email input type. Submitting opens the local file with values in its address. There is no booking handler yet.
