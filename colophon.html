How we built this site

Six local pages

We chose Golden Coffee for our project and built the site with HTML. This page is called a colophon: it explains how we made the site. The project includes a home page, a breakfast menu, a drinks page, a feedback page, a visit page and this colophon.

The HTML files are in the same folder. We used their filenames in the links, so the pages open directly from our computers without a server. Shared colours, fonts and page layout are defined in css/base.css. We have not added JavaScript.

Why we used these elements

Each breakfast and drink is inside an article because its description makes sense on its own. We used main for the page content and nav for the links. These tags make the page structure easier to understand. The address and phone number appear in every footer. 

<nav aria-label="Main navigation">
  <ul>
    <li>
      <a href="menu.html">Menu</a>
    </li>
  </ul>
</nav>

Opening the files and using the form

We open a file with Ctrl + O on Windows or Cmd + O on a Mac. The home tab shows Golden Coffee - Coffee shop in Astana. We marked the required form fields and used email and date input types. Submitting opens the local file with values in its address. There is no booking handler yet.
